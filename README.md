# Happy Holidays 2026 🎄✨

A premium, interactive holiday greeting website created for MediaTiks & MEmob+ team members.

## Features

- 🎨 **Stunning Animations** - Smooth, premium animations using advanced CSS transitions
- ❄️ **Animated Snowfall** - Beautiful rotating snowflakes with sway effects
- 🎬 **Video Section** - Professional video player for holiday messages
- 🏢 **Company Greetings** - Personalized messages for MediaTiks and MEmob+
- 🌟 **Interactive Quiz** - Discover your personalized 2026 forecast based on:
  - Zodiac sign
  - 2026 goals
  - Work style
- 📱 **Fully Responsive** - Works beautifully on all devices
- 🎨 **Brand Colors** - Custom color scheme matching MediaTiks & MEmob+ branding

## Technologies Used

- HTML5
- CSS3 (Advanced animations, gradients, transforms)
- Vanilla JavaScript
- Responsive Design

## Color Palette

- **Primary Blue**: #1e5ea8 (Memob)
- **Purple**: #6b46c1 (Blend)
- **Pink**: #c026d3, #e91e8c (MediaTiks)
- Animated gradient background

## Setup

1. Clone this repository
2. Place your holiday video as `assets/video.mp4`
3. Open `assets/index.html` in a browser

## File Structure

```
happy-holidays-2026/
├── assets/
│   ├── index.html          # Main HTML file
│   ├── video.mp4           # Holiday video

```

## Interactive Quiz

The website includes a fun, interactive quiz that personalizes 2026 forecasts based on:
- **12 Zodiac Signs** - Personalized astrological insights
- **6 Goal Categories** - Career, Health, Learning, Relationships, Financial, Adventure
- **4 Work Styles** - Team Player, Self-Starter, Leader, Creative Innovator
